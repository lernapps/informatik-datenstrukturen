# Skizzen: Netzbauer und Hypertextbaukasten

## Netzbauer (graph, pfeile)

1. Start: Aufgabe „Aufgabe Nr. 1“ über der Komponente, darunter die Liste der Freundschaften (bzw. Verweise).
   Fünf Knoten (abgerundete Rechtecke, Stil #491) im Kreis, keine Kante. Unter dem Bild: „Noch keine Kanten.“
2. Lernende tippen „Jona“: Jona ist markiert (dicker Rand, Text „ausgewählt: Jona“).
3. Sie tippen „Selin“: Linie Jona–Selin erscheint (gerichtet: Pfeil Jona → Selin). Liste darunter:
   „Jona – Selin [entfernen]“. Markierung weg.
4. Nochmals Jona, dann Selin: die Kante verschwindet (an/aus).
5. „Prüfen“ (vom Explainer): richtig → Lob; falsch → „Es fehlt eine Kante: Mia – Ben.“ / „Kante zu viel: Tom – Ali.“ /
   „Der Pfeil zeigt falsch herum: Ein Verweis führt von der Seite, auf der er steht, zur Zielseite.“
6. Tastatur: Tab durch die Knoten-Knöpfe, Enter wählt; in der Liste „entfernen“-Knöpfe.

## Hypertextbaukasten (stadtfuehrer)

1. Start: Bedingungen der Aufgabe als Liste. Fünf Karten: Startseite (hellblau), Schule, Bus, Schwimmbad, Bücherei.
   Jede Karte: Titel, „Verweise: keine“, Auswahlfeld „Verweis auf …“ und Knopf „Verweis anlegen“.
2. Verweis anlegen: Karte Startseite, Auswahl „Bus“, Knopf → Liste „→ Bus [entfernen]“.
3. Daneben kleiner Graph (Stil #491) mit Pfeilen, wächst mit.
4. Knopf „Vorschau“: zeigt die Startseite als Seite mit ihren Verweisen als Links; Klick führt zur Zielseite; „Zurück
   zur Startseite“ nur, wenn die Seite einen Verweis darauf hat (sonst Hinweis „Sackgasse: kein Verweis führt weiter“).
5. „Prüfen“: erste verletzte Bedingung mit Seite: „Die Seite Bücherei erreichst du von der Startseite nicht.“ /
   „Bis zur Seite Schwimmbad brauchst du 3 Klicks, erlaubt sind 2.“ / „Von der Seite Bus führt kein Verweis zurück zur
   Startseite.“ / „Es fehlt der Verweis von Schule auf Bus.“
